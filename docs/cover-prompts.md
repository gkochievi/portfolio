# Portal cover images — prompts for Dareke, Chiti and Azri

The portal card for each project shows `site/public/thumbnails/<slug>.webp` (4:3). All eleven
exist. Dareke, Chiti and Azri were generated last (2026-10-10), after the Higgsfield plan's
**4 generations per UTC day** cap reset (00:00 UTC, 04:00 in Tbilisi). The prompts below are the
record, in case a cover needs regenerating.

## To regenerate one

1. Generate the prompt below: model `gpt_image_2_5`, aspect ratio `4:3`, resolution `2k`, quality `high`.
2. Check the wordmark is spelled exactly right (d-a-r-e-k-e, c-h-i-t-i, a-z-r-i) and nothing else is lettered.
3. Convert: `cwebp -q 84 -resize 2000 0 in.png -o site/public/thumbnails/<slug>.webp`
4. `npm run build` — the card picks the file up with no code change.
